# Marufa Sultana Moon — Portfolio

A responsive, single-page portfolio using HTML, Tailwind Play CDN, JavaScript, GSAP, and one custom stylesheet for the mockup's unique design.

## Preview

Open this folder with a local static server, such as VS Code Live Server. An internet connection is required for the Tailwind and GSAP CDNs. No npm install or Tailwind build step is needed.

## Where to edit

- `index.html`: page content, links, and Tailwind utility classes.
- `css/portfolio.css`: the custom responsive layout, theme, and visual styles.
- `js/theme.js`: saved light/dark theme toggle.
- `js/navigation.js`: mobile menu, active section, and back-to-top behavior.
- `js/projects.js`: project filters.
- `js/animations.js`: GSAP entrance, hover, and scroll animations.
- `js/contact.js`: contact form mailto behavior.
- `assets/images/moon.jpg`: replace this image to change the portrait.

Tailwind Play CDN is convenient for mockups and development. The contact form opens the visitor's default email application; it does not store or send submissions to a server.
